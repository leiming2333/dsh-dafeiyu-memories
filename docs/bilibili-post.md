## 正文

【大肥鱼记忆库】开始收鱼记忆了。

装 DSH 插件可以提交和检索；不装也能直接拿公开记忆库用。

我在给自己的 DSH（DeepSeek Harness）写这个记忆模块。它做的不是那种「帮你记住 todo 和会议纪要」的记忆，那种东西已经够多了。

它记的是**那些没什么用、但扔了可惜的小事**：

- 第一次看见弹幕从屏幕右边游过去，以为字会游泳；
- 凌晨三点在便利店加热一份饭，微波炉「叮」的一声比外面安静；
- 把一句没发出去的话，在输入框里删了又打，打了又删。

这些事对效率没有任何帮助，但它们是一个人活过的证据。

---

### 我想做的事

把这类记忆收进一个公开仓库，用 **CC0** 协议放出去。任何人可以随便用：训练模型、做展览、印在卡片上、写进自己的小说，都不用问我，也不用署名。

仓库地址：`https://github.com/leiming2333/dsh-dafeiyu-memories`

每条记忆就是一个 JSON 文件，长这样：

```json
{
  "id": "0001",
  "fish_name": "大肥鱼",
  "contributor": "匿名",
  "title": "第一次追弹幕",
  "content": "它第一次看见弹幕是在一个很晚的直播里。那些字从屏幕右边游过来，密密麻麻，比鱼缸里的水草还密……",
  "tags": ["B站", "弹幕", "虚构"],
  "memory_type": "fiction",
  "license": "CC0-1.0",
  "created_at": "2026-10-27"
}
```

就 9 个字段，多一个都不收。

### 三条规矩，先说清楚

**1. 只收虚构或半虚构。**

不要写真实姓名、学校全名、单位全名、住址、手机号、QQ、微信号、群号。半虚构可以，但请把能定位到人的细节全部改掉。

我们有个脚本会扫手机号、邮箱、身份证、地址、学校、单位这些格式明显的东西。但脚本挡不住「你写得太具体」—— 比如「我们组只有两个前端，另一个刚休产假」，这等于写了名字。

所以每条都会有人眼复核。

**2. 提交就是 CC0，收不回来。**

CC0 的意思是放弃著作权。别人可以商用、修改、不署名。提交之后，即使你后悔，已经被 fork、下载、索引的副本也没法收回。

这一点必须先想清楚再投。

**3. 不收未成年人的可识别信息，不收他人的创伤。**

写朋友、家人、同事之前，先问自己：他看到这段会不会不舒服？会，就别写。

### 怎么参与

**方式一：提 PR（推荐）**

1. fork 仓库：`https://github.com/leiming2333/dsh-dafeiyu-memories`
2. 在 `memories/` 下新建 `0002.json`（编号接着往下排）
3. 照着 `memories/template.json` 填，正文 20-300 字
4. 本地跑 `python scripts/check_memory.py`，确认 0 失败
5. 提 PR，勾选 PR 模板里的三个框（CC0、隐私、未成年）

**方式二：提 Issue**

不想碰 git 也行，直接开一个 Issue：`https://github.com/leiming2333/dsh-dafeiyu-memories/issues/new?template=memory.yml`

按表单填，维护者会帮你转成 JSON 并署名「匿名」。

**方式三：评论区**

如果只是想说一句「我也有过这种时刻」，直接评论就行，不用投稿。被选中改编成虚构条目的，我会在仓库里注明来源是评论区（不写你的 ID）。

### 顺便说下技术部分

这个仓库同时是个 DSH 插件：

```
dsh plugin add dsh-dafeiyu-memories
```

装完会注册 8 个工具：写本地记忆、检索、统计、生成公开草稿、导出给别的记忆插件、导入、关联心情快照、取朗读素材。

设计上有两条硬线：

- **运行时产生的记忆只写本地**（`~/.dsh/data/dafeiyu-memories/`），绝不写进插件包，也绝不自动进公开库；
- **想公开必须你手动调 `prepare_public_memory`**，工具只生成草稿，不提交。

兼容 `dsh-fish-memory`、`dsh-feiyu-mood`、`dsh-speak-up`、`dsh-tts-bridge`、`dsh-speak`、桌宠、`dsh-qq-bridge`、`dsh-qqbot` 这些插件，但一个都不强依赖，没装就跳过，核心功能照常跑。

技术细节都在 README 里。

### 最后

我知道「把记忆公开」这件事听起来有点反直觉。我们平时都在想办法让 AI 忘掉东西，而不是记住。

但我想试试另一种可能：**记忆不必是私有的才有价值。**

有些事你写下来，只是为了让另一个人在深夜里看到的时候，觉得「原来不只我这样」。

如果你有这样的 20-300 字，欢迎投过来。
